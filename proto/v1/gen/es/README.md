# Generated TypeScript contract (staged)

`v1/world_pb.ts` is generated by protobuf-es v2.16.0 from
`proto/v1/world.proto` and is committed. Do not hand-edit it.

**Incomplete on purpose:** P19a stages only `Ping`, `Pong`, `JoinRoom`
and `JoinRoomResponse` (type ids 19-22). P19b-P19d add the session,
simulation and character messages, then remove the temporary `types`
filter. Until P19d lands, this is an intermediate client contract, not
the full public surface.

Regenerate from the repository root:

```sh
npm ci
make proto-es
```

Consumers import from `@bufbuild/protobuf` v2 with extensionless paths.
